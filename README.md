# Dinkum 통합팩

Windows용 비공식 Dinkum 모드 관리자입니다. 설치할 기능과 단축키를 선택하고, 변경 파일을 백업하며, 관리 대상 모드를 최초 적용 전 상태로 복원할 수 있습니다.

## 다운로드

배포 파일은 **[Releases](https://github.com/Nami-491/dinkum/releases)**에서 제공할 예정입니다. 아직 업로드되지 않았다면 릴리스 목록은 비어 있습니다. GitHub의 자동 생성 `Source code` ZIP은 실행 설치 파일이 아닙니다.

배포 ZIP을 압축 해제한 후 `Dinkum-Modpack-Setup.exe`를 실행하세요. 게임 실행 중에는 적용할 수 없습니다. 방장·참가자 전원 장비 강화 **1.2.0**을 사용해야 합니다.

## 4.2 변경 사항

- 강화 최대 +20, 비용은 게임 내 **딩크(Dinks)만** 사용합니다.
- +10까지 실패 유지. 현재 +11 이상 장비가 실패하면 1단계 하락하며 +10 아래로 내려가지 않습니다. 파괴는 없습니다.
- +20 공격력·채집 타격 성능 1000%, 최대 내구도 1600%. 성공·실패 모두 비용을 냅니다.
- 기존 +1~+10 장비 번호 보존, 구 강화 저장의 명시적 백업·호환성 변환 기능.
- 방장 전용 강화 장비 찾기·선택 회수(+20 지원), 사용자별 단축키 변경, 설치 전 백업/복원.

상자 재료 제작·요리, 상자 보내기, 개별 아이템 잠금, 기본 판매가격, NPC 선호 음식·지도 표시, 생물 겹치기도 포함합니다. 기존 MorePlayers 설정은 수정하지 않습니다.

## 반드시 확인

- 확인한 Steam 빌드 **25568182**만 지원합니다. 다른 게임 빌드는 안전을 위해 차단합니다.
- 기존 강화 1.0 저장은 게임 업데이트 후 저장했는지에 따라 처리 방법이 다릅니다. 동봉한 **사용법.md**를 먼저 읽으세요. 상태를 모르면 자동 변환하지 마세요.
- 강화 1.1 변환이 끝난 PC도 DLL은 1.2.0으로 업데이트해야 합니다.
- 실제 원격 멀티 및 20인 동시 플레이 안정성은 보장하지 않습니다. 테스트 섬과 백업을 사용하세요.
- 복원 전 강화 장비를 일반 장비로 변환하고 생물 묶음을 분리해야 합니다. 설치기의 복원은 세이브 롤백이 아닙니다.
- 개인 제작 미서명 EXE입니다. 보안 프로그램을 끄지 마세요.

게임 원본 DLL·세이브·개인 로그·계정 정보는 배포하지 않습니다. 원작자의 공식 배포물이 아닌 로컬 호환성 구현이며, 출처와 포함 구성요소 고지는 패키지의 `NOTICE.txt`와 `Mono.Cecil-LICENSE.txt`를 확인하세요.
