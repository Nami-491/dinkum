## 남은 제한 및 관찰된 오류

- **+20의 디스크 직렬화 내용은 확인했지만, +20 장비를 유지한 상태로 게임을 종료·재실행하여 다시 로드하는 검사는 하지 않았습니다.**
- 실제 다른 PC 접속·20인 동시 접속·제작·상자 전송·접속 단절 중 거래는 미검증입니다. 로컬 호스트 검사는 네트워크 외부 리스닝 없이 수행했습니다.
- 회수는 기존 강화 드롭을 검색하는 것만 확인했습니다. 실제 발밑 이동·줍기 및 원격 동기화는 미검증입니다.
- Legacy는 빌드·설치기 선택을 검사했으며 현재 게임에서 Legacy 로더로 실행하지 않았습니다.
- `WindowAnimator.AnimateOpen` 시작 예외와 `Vehicle.OnDestroy` 종료 예외가 남았습니다. 시작 예외는 앞선 별도 비교에서도 관찰됐습니다. 이번 작업으로 모든 오류를 해결했다거나 무시해도 된다고 판단하지 않습니다. BepInEx Unity 로그 기록기 시작 경고도 관찰했습니다.
- 원본 세이브에 초기 복원·제거 변환을 실행하지 않았습니다. 신규 세이브/변환 UI의 모든 수동 클릭 경로를 실사용 검증한 것은 아닙니다.
- 동시 제작 재료 차감, 상자 전송 중 강제 종료까지 포함한 아이템 보존은 완전히 보장하지 않습니다.

## 배포 안전 범위

ZIP은 설치 EXE·런타임 설정·사용법·검증 요약·출처/라이선스·SHA-256 목록만 포함합니다. 게임 원본 DLL, 사용자 저장·로그, QA 자동 조작 플러그인, 인증 정보는 포함하지 않습니다. EXE는 미서명입니다. 보안 프로그램을 끄지 말고, 중요 세이브는 백업 후 복사본에서 먼저 확인하세요.
