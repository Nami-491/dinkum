# Dinkum 통합팩 4.2 — +20 강화 / 딩크 전용 비용

비공식 실험적 수정판입니다. Steam 빌드 **25568182**에서 확인한 게임 파일만 지원하며, 다른 빌드는 설치가 차단됩니다. 중요한 섬은 백업하고 복사본에서 먼저 확인하세요. 방장과 참가자 **전원 장비 강화 1.2.0**으로 맞춰야 합니다.

## 설치

1. Dinkum을 완전히 종료하고 ZIP을 새 폴더에 압축 해제합니다.
2. `Dinkum-Modpack-Setup.exe`를 실행합니다.
3. `Dinkum.exe`가 있는 폴더가 맞는지 확인합니다. 참가자는 기본 선택 7개를 적용합니다. 방장은 원할 경우 마지막 **강화 장비 찾기**도 선택합니다.
4. 필요하면 **단축키 설정**에서 키를 변경하고 **선택 모드 적용**을 누릅니다.
5. 구 강화 세이브라면 아래 호환성 절차를 먼저 확인합니다.

Modern/Legacy는 기존 BepInEx 로더를 보고 자동 선택합니다. 로더가 없으면 공식 BepInEx 파일을 다운로드하고 해시를 확인합니다. 이미 설치된 정상 로더는 유지합니다. BepInEx 5나 혼합 로더는 지원하지 않습니다.

선택을 해제해도 이미 설치된 모드를 삭제하지는 않습니다. 기존 단축키는 명시적으로 바꾸지 않으면 보존합니다. 서명되지 않은 개인 제작 EXE이며 보안 프로그램을 끄지 마세요.

이 팩은 **MorePlayers를 설치·변경하지 않습니다**. 기존 방장의 MorePlayers 0.4.0 / 20명 설정은 유지됩니다. MorePlayers 0.3.0이 있으면 먼저 별도 호환성 확인이 필요합니다. 20명 동시 플레이 안정성을 보장하지 않습니다.

## 기존 캐릭터의 세이브 호환성

게임 업데이트로 기본 아이템 번호가 늘어 구 강화 1.0 저장과 충돌할 수 있습니다. 모드 DLL만 교체한 뒤 구 캐릭터를 바로 로드하지 마세요.

게임 첫 화면에서 **참가자 세이브 호환성 설정**을 열고 각 Slot의 실제 상태를 선택합니다.

| 저장 상태 | 선택 및 조치 |
| --- | --- |
| 구 강화 1.0 사용, 이번 게임 업데이트 후 정상 플레이·저장한 적 없음 | `구 강화 1.0 / 업데이트 후 저장 없음`. 기존 강화 아이템 번호를 +38 이동합니다. |
| 강화 모드를 사용한 적 없는 기존 세이브 | `강화 모드 사용 안 한 저장`. 번호를 이동하지 않고 검사합니다. |
| 이미 강화 1.1 호환성 변환을 완료한 세이브 | 재변환 없이 사용 가능합니다. 설정 화면을 이용한다면 `이미 1.1/1.2로 변환한 저장`을 선택합니다. |
| 새로 만들 캐릭터로 기존 저장 없음 | 변환 없이 새 캐릭터를 만듭니다. |
| 구 강화 상태로 업데이트 후 플레이·저장했거나, 상태를 모름 | **변환하지 말고 별도 점검을 요청하세요.** 잘못 선택하면 기본 아이템과 강화 아이템을 오인할 수 있습니다. |

모든 Slot의 종류를 확인한 뒤 백업·변환을 실행하고 게임을 재시작합니다. Steam Cloud 동기화·세이브 복사와 동시에 실행하지 마세요. `.dat` 구형 저장은 자동 변환하지 않습니다.

원본은 게임 세이브 폴더 안의 `LocalEnhancementMigrationBackups`에 보존합니다. 변환 중 중단되면 다음 실행 시 먼저 복구 버튼을 사용합니다. 외부에서 파일이 변경되었거나 백업이 손상되면 자동 복구는 멈춥니다. `.pending` 표시나 백업·강화 요청 기록을 임의로 지우지 마세요.

기존 방장 PC처럼 이미 1.1로 변환된 경우 강화 단계와 아이템 번호는 유지되며 +11~+20 번호만 뒤에 추가됩니다. **방장도 새 EXE로 1.2.0을 적용해야 합니다.**

## 장비 강화

인벤토리에서 지원 장비를 가리키고 **F11** → 수치·확률·딩크 확인 → **강화 시도**를 누릅니다. 창을 여는 것만으로는 비용이 들지 않습니다.

- 최대 **+20**, 실패해도 파괴 없음.
- 현재 +0~+10에서 실패: 유지. **+10 → +11 시도 실패도 +10 유지**.
- 현재 +11~+19에서 실패: 1단계 하락, 최저 +10.
- 성공·실패 모두 **딩크만 차감**. 구리·철 주괴 등 아이템 재료 불필요.
- 무기: 공격력과 최대 내구도. 도끼·곡괭이: 채집 타격 성능과 최대 내구도.
- +10: 성능 220%, 내구도 320%. +15: 성능 510%, 내구도 810%. +20: 성능 1000%, 내구도 1600%.
- 내구도는 남은 비율을 유지하며 정수로 계산합니다. 일반 사용 시 내구도는 소모됩니다. 채집 수량 증가·무료 완전 수리가 아닙니다.
- 강화 요청 중에는 게임을 종료하거나 방에서 나가지 마세요. 미완료 요청은 기록을 보존하므로 오류 시 기록을 삭제하지 마세요.

| 목표 단계 | 성공 확률 | 시도당 딩크 |
| --- | ---: | ---: |
| +1~+3 | 90% | 2,000 |
| +4~+6 | 70% | 5,000 |
| +7~+9 | 45% | 10,000 |
| +10 | 25% | 20,000 |
| +11~+13 | 20% | 30,000 |
| +14~+16 | 15% | 50,000 |
| +17~+19 | 10% | 80,000 |
| +20 | 5% | 150,000 |

## 기존 기능과 기본 키

| 기능 | 기본 키 / 범위 |
| --- | --- |
| 본섬 일반 상자 재료 제작·요리 | 제작대에서 사용. 방장과 사용자 설치. 거리 제한 없는 본섬 야외 일반 상자와 현재 실내의 상자 조회. 다른 건물 실내·지하·다른 섬은 제외하며, 동시 제작 재료 차감의 완전한 안전성은 보장하지 않습니다. |
| 인벤토리 정렬 | F6. 게임 기본 정렬, 잠금 제외. |
| 상자 보내기 | F7. 기본 30타일, 같은 실내·구역의 닫힌 일반 상자, 이미 들어 있는 종류만. 단축바·잠금·증서·배낭·특수 보관함 제외. |
| 개별 아이템 잠금 | 가리키고 F8. 선택한 복사본/묶음만 자동 정렬·상자 보내기 제외. 내 인벤토리 이동만 추적, 밖으로 꺼내면 유지 안 함. 수동 이동·사용 허용. |
| NPC 지도 위치 | F9. 본섬 지도, 실내는 입구, 2초 갱신/6초 만료. 방장+사용자 설치. |
| 기본 판매가격 | F10. 개당·묶음, 면허·판매처·행사 보너스 미반영. |
| NPC 선호 음식 | 대화 화면의 표시 기능. |
| 물고기·곤충 겹치기 | 생물 묶음/일반 상자 보관. 제거 전 1마리씩 분리. |
| 강화 장비 찾기 — 방장 선택 기능 | F5 검색, Shift+F5 다음, Ctrl+F5 두 번으로 선택 회수, Alt+F5 닫기/취소. |

찾기는 **현재 로드된 강화 드롭**만 대상으로 합니다. 같은 구역의 기존 드롭을 발밑으로 이동하며 새 아이템을 생성하지 않습니다. 다른 참가자의 장비도 검색될 수 있으니 소유자를 확인하세요. 월드 저장 전체에서 사라진 장비를 복원하는 기능은 아닙니다.

근처 상자 전송은 접속 종료·강제 종료까지 포함한 아이템 보존을 완전히 보장하지 않습니다. 처리 중 종료하지 마세요. 실제 원격 멀티 회수, 20인 동시 제작·전송은 미검증입니다.

## 제거·복원

1. 생물 묶음을 1마리씩 분리합니다.
2. 강화 모드를 제거하려면 게임 첫 화면의 **강화 모드 제거 준비**로 일반 장비 변환을 완료합니다. 장비는 남지만 강화 단계는 제거됩니다. 원본 백업은 남깁니다.
3. 게임 종료 후 설치기의 **적용 전 초기 상태로 복원**을 실행합니다.

초기 상태는 이 통합팩 최초 적용 직전의 관리 대상 모드·설정이며, 순정 게임이나 과거 세이브 시점이 아닙니다. 세이브 호환성 변환의 되돌리기와도 별개입니다. 다른 참가자는 자신의 PC에서 처리해야 합니다. **+20 저장에 구 DLL·구 설치기를 덮어쓰지 마세요.**

자세한 검증 범위는 `검증내역.md`, 출처와 제한은 `NOTICE.txt`를 확인하세요.
