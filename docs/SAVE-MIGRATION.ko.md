# 로드·저장 차단 시 세이브 호환성 설정

**4.2.1에서 슬롯 선택과 구형 잔여 파일 처리를 개선했습니다.** 구형 파일 때문에 4.2에서 중단됐다면 새 설치 ZIP으로 장비 강화 모드를 업데이트하세요. 강화 플러그인 표시는 접속 호환성을 위해 1.2.0을 유지하며, 변환 화면 제목으로 4.2.1을 확인할 수 있습니다. 로딩 차단 이후의 상위 게임 진입 흐름 수정은 포함하지 않습니다.

대상 메시지:

```text
Equipment compatibility: load/save blocked.
Old/unmarked save requires verified equipment-ID migration. Do not save or remove this mod.
```

이 메시지는 저장에 필요한 호환성 표시가 없거나 인식되지 않아 불러오기·저장이 차단됐다는 뜻입니다. 원래 외형이 아닌 캐릭터가 보이거나 조작이 안 돼도 그것만으로 기존 캐릭터 삭제를 뜻하지는 않습니다. 다른 오류에는 이 절차를 임의로 적용하지 마세요.

## 먼저 저장 이력 확인

| 해당 캐릭터의 실제 이력 | 처리 |
| --- | --- |
| 구 강화 1.0 사용, 이번 게임 업데이트 후 정상 플레이·저장한 적 없음 | 아래 구 강화 변환 절차 대상입니다. |
| 구 강화 상태로 업데이트 후 정상 플레이·저장했거나 이력을 모름 | 자동 변환하지 말고 전체 Slot 복사본과 로그를 점검해야 합니다. |
| 강화 모드 사용 이력 없음 | `강화 모드 사용 안 한 저장`을 선택합니다. 구 강화 변환을 선택하지 마세요. |
| 이미 강화 1.1/1.2 호환성 변환 완료 | 보통 재변환 불필요. 같은 차단이 나오면 백업 후 별도 점검하세요. |

## 구 강화 1.0 / 업데이트 후 저장 없음

1. 게임을 완전히 종료합니다. 현재 멈춘 세션에서 저장하거나 새 캐릭터를 만들지 마세요.
2. 해당 참가자 PC의 아래 폴더 **전체를 다른 위치에 복사해 백업**합니다.
   ```text
   %USERPROFILE%\AppData\LocalLow\James Bendon\Dinkum
   ```
3. Steam Cloud 동기화가 끝난 것을 확인합니다. 변환 중에는 파일 복사·동기화·다른 게임 실행이 겹치지 않게 합니다.
4. 게임을 다시 실행하되 **캐릭터 선택이나 서버 접속을 하지 않습니다.**
5. 첫 화면의 **참가자 세이브 호환성 설정**을 엽니다.
6. 해당 Slot은 **구 강화 1.0 / 업데이트 후 저장 없음**을 선택합니다. 다른 Slot은 각각의 실제 이력에 맞춰 선택하거나 **이번에는 건너뛰기 (변경 안 함)**를 선택합니다. 모르는 슬롯을 추측해서 변환하지 마세요. 버튼을 클릭할 때마다 선택지가 바뀝니다.
7. **선택 확인 및 변환 준비** → 내용을 확인하고 **백업·변환 실행**을 누릅니다.
8. 완료 메시지를 확인한 뒤 게임을 완전히 종료하고 재실행하여 캐릭터를 선택·접속합니다.

이는 구 강화 아이템 번호를 새 게임 번호에 맞추는 변환입니다. 강화 단계와 내구도, 그 외 저장 필드는 보존하도록 구현·검사했습니다. 참가자 개인 파일을 직접 검사한 결과를 보장하는 것은 아니므로 외부 복사 백업을 먼저 만드세요.

## 4.2.1의 지원 범위

- 선택 슬롯에 `Player.es3`가 있어야 합니다. Player/Container의 `.es3`, `.es3.bak`, `.es3.bac`, `.es3.enhancement-backup`만 변환합니다.
- 같은 폴더의 구형 `playerInfo.dat`, `npc.dat`, `Chests/*.dat`, 과거 개별 `.es3`는 역직렬화·수정하지 않습니다. 검사 대상으로 발견된 원본은 백업하며, 건너뛴 파일도 동시 변경 검사에 포함됩니다.
- 구형 파일 때문에 다른 현대 슬롯까지 중단되던 문제를 해결합니다. `Player.es3` 없는 구형 전용 슬롯은 건너뛰세요. 순수 구형 저장을 현대 게임 저장으로 가져오는 기능은 아닙니다.
- 강화 장비가 현재 없더라도 구 강화 모드로 저장했다면 **구 강화**를 선택해야 합니다. 확장된 아이템 목록도 변환 대상입니다.
- 성공한 슬롯의 원래 장비 번호를 다시 +38하지 않도록 기존 변환 표식을 확인합니다.
- 모든 슬롯을 건너뛰거나 종류를 정하지 않으면 변환하지 않습니다. 지원하지 않는 저장을 선택해도 변경 전 중단합니다.
- 파일 집합·해시 검사, 원본 백업, 중단 시 복구 안전장치를 유지합니다. 동기화·강제 종료까지 포함한 완전한 데이터 보존 보장은 아닙니다.

## 잘못 누르지 않도록 주의

- **강화 모드 제거 준비**는 다른 기능입니다. 이 기능은 강화 수치를 없애므로 호환성 변환 대신 누르지 마세요.
- 설치기의 **적용 전 초기 상태로 복원**도 세이브 호환성 복구가 아닙니다.
- 모드 DLL, `.pending` 표시, 백업·요청 기록을 임의로 삭제하지 마세요.
- 변환 버튼이 없거나 변환 오류가 나면 반복 시도하지 말고 화면과 해당 PC의 `BepInEx/LogOutput.log`를 보존하세요. 구형 `.dat` 저장은 자동 변환하지 않습니다.
- 중단된 변환 표시가 있으면 제공되는 복구 기능부터 사용합니다. 외부 파일 변경 때문에 복구가 거부되면 수동으로 표시를 지우지 말고 점검하세요.

## 알려진 제한

4.2/4.2.1에는 불러오기를 차단한 뒤에도 상위 게임 진입 절차가 계속될 수 있는 경로가 있습니다. 이번 변환기 개선이 그 코드까지 수정했다는 의미는 아닙니다. 차단 후 메뉴로만 돌아가 반복 접속하지 말고 게임을 완전히 종료·재실행하여 첫 화면에서 처리하세요.

전체 기능·제거 절차는 [사용법](USAGE.ko.md), 검증 범위와 남은 오류는 [검증 내역](VALIDATION.ko.md)을 참고하세요.
