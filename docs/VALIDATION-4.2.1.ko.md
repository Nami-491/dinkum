# 4.2.1 검증 범위

이 배포는 게임 내 선택 슬롯 변환기를 개선한 테스트 배포입니다. 실제 게임이 실행 중이어서 라이브 설치·세이브 변환·게임 내 화면·멀티 접속 검증은 수행하지 않았습니다.

## 이번에 통과한 검사

- modern/legacy 강화 DLL과 Windows 설치기 빌드: 오류·경고 0개.
- 순수 슬롯 선택 정책: 25개. 현대/구형 혼재, 구형 전용 슬롯 거부, 슬롯 건너뛰기, 미선택/전체 건너뛰기 거부, 경로 이탈 거부, 허용 백업 파일 범위를 검사했습니다.
- 설치 패키지: 35개. 플러그인 GUID, 의존성, modern/legacy 4.2→4.2.1 업데이트 허용, 미완료 강화 요청 시 차단, 알 수 없는 게임 차단 등. 실제 설치는 하지 않았습니다.
- 강화 DLL의 변환기 외 코드 비교: 두 로더 합계 444개 메서드 본문과 각 6개 상수 일치. 기존 장비 번호, 강화 규칙과 네트워크 지문 생성 코드는 변경하지 않았습니다.
- 원본 교체/원복 경로는 검사 대상 전체를 기록하되, 실제 전후 해시가 다른 파일만 교체하도록 검토했습니다. 선택하지 않은 파일은 백업·동시 변경 검사만 합니다.

기존 4.2의 실제 게임 검증은 [이전 기록](VALIDATION.ko.md)을 참고하세요. 이를 4.2.1 변환기의 새 실행 검증으로 간주하면 안 됩니다.

## 남은 제한

- `Player.es3` 없는 순수 구형 저장은 지원하지 않습니다. 선택 시 중단하며 건너뛰기가 가능합니다.
- 구 강화 상태로 게임 업데이트 후 이미 저장했거나 이력이 불명확하면 자동 변환하지 마세요.
- 로딩 차단 후 기본 외형의 필드로 진입하는 상위 게임 흐름 문제는 이번 수정 범위가 아닙니다.
- 개인 세이브·게임 DLL·개인 로그는 공개 패키지와 소스에 포함하지 않습니다.
- 원격 멀티/20인 실전 안정성, 정전·강제 종료·Cloud 동기화까지 포함한 데이터 보존을 보장하지 않습니다.

외부 전체 백업을 만든 뒤 시험용 복사본으로 먼저 확인하세요.
