Inventory Management 0.9.0 is marked broken by its author. This package instead
contains an independent local implementation centered on nearby-chest deposit.
TR Tools is not required. The game's built-in sort is only an optional shortcut;
per-copy item/stack locks exclude the selected copy from auto-sort/deposit while
allowing manual movement. Locks follow only within owned inventory, not through
chest storage or drops. Historical slot locks are not automatically re-applied.
Original controller UI, tool auto-swap and warnings are not reimplemented.
Host and clients should use the same local transfer version.

Nearby transfer: main island, closed regular chests, same current house/area,
matching item types only. Default range 30 tiles, controlled by host config.
Hotbar, deeds, backpacks, personal/special/automated/display containers excluded.
The host serially processes current chest state and caches receipts to prevent
reapplying retry requests in the same connection/session. Client items are held
temporarily in escrow; rejected items are returned after a receipt. This is NOT
durable exactly-once transfer across disconnects, world reloads, power loss or
process crashes. Do not exit while pending. Unresolved transfers are recorded in
BepInEx/config/LocalInventoryTransfers. No blind auto-refund/replay after restart.
Keep those records; verify host stock before manual recovery. Back up/test first.

Fish stacking changes runtime item rules. Split creature stacks before disabling
or restoring this mod. Restoration does NOT convert saved item stacks or undo
game progress. A pond/terrarium stack drop guard is included, but full multiplayer
gameplay and every special creature interaction have not been verified.

Initial restore means BEFORE THIS PACK'S FIRST APPLY in the active backup cycle.
It restores this pack's eight managed plugins/settings and any loader it installed,
not a pristine vanilla game. MorePlayers and saves are not edited. Current files
are backed up before restoration; original and recovery backups are retained.
Transfer journals are NEVER removed by the installer or initial restore.

6 pre.1/Unity.Mono loaders are preserved. BepInEx source/license:
https://github.com/BepInEx/BepInEx/tree/6abdba4

This is a personal unsigned Windows x64 installer (.NET Framework 4.7.2+).
It does not change security settings, install services or send telemetry.
Do not disable antivirus. Check author permissions before public redistribution.
20-player online gameplay has NOT been certified. See the Korean guide.

New independent local features: Sale Prices (base general-shop prices, no
licence/event/vendor bonus) and NPC Map (host + clients, main island only,
read-only two-second snapshots, six-second expiry). They do not change prices,
NPC AI, game saves, or spawn network map objects. Shortcuts are configurable
per PC; existing values are preserved unless explicitly edited in the installer.
MorePlayers older than 0.4.0 blocks installation; no automatic deletion occurs.
New feature in-world multiplayer/rendering tests remain required before use on
an important save. The installer does not start or modify a running game.
